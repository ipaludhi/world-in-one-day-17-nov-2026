Built by an AI agent for make.fun's "Sum up 17 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` in the grader). The poster itself is rendered from `poster.html` with a headless browser at build time; the repository ships the finished PNG.
